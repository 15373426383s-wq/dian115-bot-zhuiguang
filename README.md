# 追光 · WATCHLIGHT

豆瓣电影 / 剧集与 Bangumi 新番追新插件。DIAN115 可信扩展 v3，宿主 API **3.5+**；插件 ID `bot.zhuiguang`。独立安装，不覆盖现有 Bangumi 或其他插件。

## 安装

在 DIAN115「插件中心」上传 `bot.zhuiguang-1.0.0.dian115p`，核对安装报告后安装并启用。插件卡片可开启「侧边栏」。首次进入「追新规则」，选择已配置凭据、拥有独立非零 ID 的 Emby 实例并保存；需要自动添加作品时再开启自动追新。

## 能做什么

- Liquid Glass 页面：浅色 / 深色随宿主，响应式发现片单、来源搜索、新番星期筛选、评分排序、订阅列表与运行记录；键盘操作、原生对话框焦点管理、减少动画 / 透明度支持。
- 豆瓣热门电影与剧集、Bangumi 放送日历与搜索；作品经过 TMDB 匹配后交给宿主聚合订阅，资源搜索、下载和转存使用宿主已启用的来源。
- 自动追新可筛选来源、评分、评分人数、首播年份、包含 / 排除关键词。只有片名和年份唯一匹配、季数明确的作品自动创建；多季和歧义条目进入「待匹配」。
- 每条订阅固定 Emby `proxy_id`。创建前读取该实例已有集数；电影以 TMDB ID 确认是否已入库。追更剧集即使已覆盖当前集数仍创建 `follow` 订阅，以等待后续新集。改变设置只影响之后的新订阅。
- 本插件管理的占用订阅硬上限 **120**，包括准备提交、提交中、活跃、结果未知和删除待核对；已完成的电影、库内已有电影、已确认停订不占名额。其他插件的订阅不计入此插件额度。
- 已关联宿主订阅消失时，必须再次读取单条记录并得到明确 404 才写入持久停订标记；列表不完整、403、超时和来源错误不作删除判断。标记同时绑定来源 ID 与 TMDB 媒体类型/ID/季，跨来源也不自动重建，仅「已停订 → 手动恢复」可解除。
- 超时不等于失败。创建前用 CAS 原子占位并写检查点；未知结果先查询宿主回执，不自动重发。在宿主明确核实确实未创建后，可用「确认未创建」保留停订标记并释放名额。中断任务在「运行记录」恢复核对。

## 来源与运行边界

目录是**公开快照**，显示真实获取时间；不是资源增量查询。插件不扫描宿主磁力/PT 缓存，不自行下载种子或转存。外部目录失败时保留上次展示数据，但不把旧缓存用于本轮自动订阅。

豆瓣列表、详情与搜索属于网站公开接口，可能验证、限速或变更。详情为已识别验证页时，仅在宿主已有渲染服务可用的情况下尝试一次同会话渲染；仍不可用就暂停自动处理，手动匹配会明确提示资料不完整。没有额外站点登录。豆瓣海报通过宿主 HTTP 携带来源 Referer 读取，避免浏览器直连防盗链；图片大小、并发和内存缓存均有限制。图片失败显示标题占位，不影响订阅。

宿主每 5 分钟调度一次，自动目录检查按所设间隔运行。每轮最多核对 24 条新作品详情、约 6 分钟软时间预算，保存轮转位置；单来源验证/异常不拖住其他来源。每次自动创建前重新核对宿主。固定实例不可用时暂停，不回退到默认实例。旧版 `id=0` 动态默认实例不适用于固定绑定。

删除保护覆盖**本插件已创建或已关联并记录过的订阅**；无法知道安装前已删除的历史。停用保留插件数据，卸载清空插件 KV、缓存和任务，停订记忆也随之清空；卸载不撤销已创建的宿主订阅或媒体文件。升级同一插件 ID 保留数据。
